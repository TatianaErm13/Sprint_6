Sprint_6

Автоматизированные UI-тесты для учебного сервиса «Яндекс.Самокат».

Описание проекта

В рамках проекта реализованы UI-тесты для проверки основного функционала сервиса «Яндекс.Самокат».

При разработке использованы:

Selenium WebDriver;
Pytest;
Page Object Model (POM);
Allure Report.

Проект покрывает следующие сценарии:

проверка работы блока «Вопросы о важном»;
оформление заказа самоката с двумя наборами тестовых данных;
проверка перехода по логотипу «Самокат»;
проверка перехода по логотипу Яндекса на страницу Дзена.

Реализованные проверки
Вопросы о важном

Проверяется:

открытие каждого вопроса при нажатии на стрелку;
отображение соответствующего текста ответа.

Для каждого вопроса используется отдельный тест с параметризацией.

Заказ самоката

Позитивный сценарий оформления заказа:

Нажатие кнопки «Заказать».
Заполнение формы заказа.
Подтверждение заказа.
Проверка появления окна об успешном создании заказа.

Используются два набора тестовых данных.

Проверка логотипов
Логотип «Самокат»

Проверяется переход на главную страницу сервиса.

Логотип Яндекса

Проверяется открытие новой вкладки и переход на страницу Дзена.

Установка зависимостей
pip install -r requirements.txt
Запуск тестов

Запуск всех тестов:

pytest

Запуск с подробным выводом:

pytest -v
Формирование Allure-отчёта

Запуск тестов с сохранением результатов:

pytest --alluredir=allure_results

Построение отчёта:

allure serve allure_results

или

allure generate allure_results -o allure_report --clean
allure open allure_report
